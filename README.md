# ハヌマーン言語
ハヌマーン言語はロックバンド、ハヌマーンにインスパイアされたジョークプログラミング言語です。  
キーワードがハヌマーンの歌詞になっています。

## サンプルコード
いきなりですが、サンプルコードです。

ここではハヌマーン言語では**一行につき一つの命令**が書かれることに気をつけてください。  
また、\#で始まる行はコメントとして無視されます。

### Hello world
```
捨て看板の女がぼやく「Hello world!」
```

## 基本的な概念
この章ではハヌマーン言語の基本を紹介します。

ちなみにハヌマーン言語はBrainfu○k言語(以下BF言語と表記)にかなりインスパイアされています。  
このREADMEはBF言語の知識がなくても読めますが、BF言語の基本的な知識があるとより理解が簡単になると思います。

ハヌマーン言語はBF言語同様に、配列と配列上の要素を指定するインデックスを内部的に持っています。  
この配列を操作することで色々な処理をしていきます。

具体的には、プログラムの起動時に長さ2^16(65536)の符号付き32ビット整数配列を初期化します。この配列の全ての要素が0で初期化されています。またインデックスの初期値は0です。  
イメージとしてはこんな感じです。
```
32bit整数の配列
|0|0|0|0| ... |0|
 ↑
インデックス = 0
```

以下の歌詞は現在のインデックスが指す要素の値をプリントする歌詞です。
```
換気口の下でギニアピッグが云う
```

出力結果は`0`になります。


## 要素の四則演算
それではプログラムを書いてみましょう。

ここでは配列の要素に四則演算をするプログラムを書いていきます。

まずは現在の要素に1を足して結果を表示するプログラムです。
```
たった1秒でも長く眠りたい
換気口の下でギニアピッグが云う

# 出力結果：1
```

このプログラムを実行すると要素0(インデックスの初期値が0のため要素0を操作します)に1が足され、配列は次のように変化します。  
```
|1|0|0|0| ... |0|
 ↑
インデックス = 0
```

ハヌマーン言語には四則演算とmodは以下の通りです。
```
# 1を足す
たった1秒でも長く眠りたい
# 2を引く
見張り番の俺の落ち度を糾弾2円奪って先輩消える
# 3をかける
ヘッドホンをして3秒ごとに変わる表情 
# 4で割る
零コンマ4秒で片付く命
# mod17を計算する
何しろ僕らは17歳だった
```

この他にも乱数や値をゼロにリセットする歌詞が用意されています。詳細はキーワードの章を参照してください。  

## インデックスの移動
0以外の要素を操作したい場合は以下の歌詞でインデックスを移動します。  
```
# インデックスを要素2に移動する
演奏ハヌマーンでアナーキー・イン・ザ・2K
```

インデックスは0~65535である必要があります。

## 標準出力に表示
ハヌマーン言語にはいくつか表示に関連する歌詞があります。  
各歌詞の挙動については、以下の表を参照してください。

| 歌詞 | 機能 |
| --- | --- |
| 換気口の下でギニアピッグが云う | 要素の値を数字として表示 |
| こめかみを指して痩せた鴉が云う | 要素の値をunicode pointとして解釈し文字を表示 |
| 捨て看板の女がぼやく「X」 | Xを標準出力にプリント (Xは任意の文字列) |
| CR人間模様気付けばそれの虜になってる| 改行を標準出力にプリント |

*補足* Unicode pointは21bitの整数で表されますが、ハヌマーン言語の要素は32bit符号付き整数を保持できるため、unicode pointに存在しない値を表示しようとするとエラーが出ます。

## ループ
ループ開始の歌詞を書くと、現在の要素の値が0でないときのみループ内に入ります。  
これもBF言語と同じ挙動です。

ループを使ったサンプルコードです。
```
# 30から1までの数字を表示する例

# 現在の要素の値を30にする
たった30秒でも長く眠りたい

# ループ開始
気に喰わんね輪廻の概念
 # 現在の要素の値を表示
 換気口の下でギニアピッグが云う
 CR人間模様気付けばそれの虜になってる

 # 要素をデクリメント
 見張り番の俺の落ち度を糾弾1円奪って先輩消える

# 要素が0ならループ終了
全くを以って気に入らないね
```

## 条件分岐

条件分岐は３つの歌詞を用います。サンプルを見てみます。  
```
# 現在のセルが17の倍数か判定
何しろ僕らは17歳だった

どうして?の問いに
 # 要素が0以外
 捨て看板の女がぼやく「17の倍数」
 CR人間模様気付けばそれの虜になってる

愛してるって
 # 要素が0
 捨て看板の女がぼやく「17の倍数ではない」
 CR人間模様気付けばそれの虜になってる

答えになってないぜ兄さん
```

サンプルから分かる通り以下のような文法になっています。
```
どうして?の問いに
 {then部：現在のセルが0でないときに実行される}
愛してるって
 {else部：現在のセルが0のときに実行される}
答えになってないぜ兄さん
```

この３つの歌詞は省略不可で、例えif部またはelse部だけを実行する際も３つの歌詞が必要です。
```
どうして?の問いに
 {if部}
愛してるって <- 省略不可
答えになってないぜ兄さん <- 省略不可
```

ワンナイトアルカホリックの歌詞が好きな場合は以下のように書くことでコードの実行結果を変えることなく歌詞をコードに追加できます。

```
# 以下のコードは実行結果に関係ないぜ兄さん
どうして?の問いに
愛してるって
答えになってないぜ兄さん
```

## 関数
ハヌマーン言語は関数の宣言と呼び出しをサポートしています。

以下が文法です。

```
# Hello World関数を宣言
そういちいち怒鳴るなって誰だってHello Worldを表示したい
 捨て看板の女がぼやく「Hello World」
言う？武闘派に遭遇して同じように言う？

# Hello World関数を呼びだし
もういちいち言わんだけで俺だってHello Worldを表示したい
```

`そういちいち怒鳴るなって誰だってXXXしたい`の`XXX`の部分が関数名になります。  
`言う？武闘派に遭遇して同じように言う？`は関数を閉じるために使います。  

## 要素参照
（要素参照はハヌマーン言語のために作者が勝手に考えた~出鱈目な偽名~言葉で、一般的なプログラミング用語ではありません。）  
四則演算とインデックスの移動は要素参照をサポートしています。  
例えば要素0の値を要素1にコピーしたい場合、要素参照を使わないと以下のようなコードを書く必要があります。  

```
# 要素0の値を要素1にコピー
気に喰わんね輪廻の概念
 # 要素1をインクリメント
 演奏ハヌマーンでアナーキー・イン・ザ・1K
 たった1秒でも長く眠りたい

 # 要素0をデクリメント
 演奏ハヌマーンでアナーキー・イン・ザ・0K
 見張り番の俺の落ち度を糾弾1円奪って先輩消える
全くを以って気に入らないね

```

このコードは動きますが、以下の問題点があります。  
- 要素を1ずつループするので特に大きな数字では効率が悪い
- コード実行後、要素0の値は0になっており、値が保存されない

要素参照を使うことで以下のように書けます。  

```
# 要素0の値を要素1にコピー
演奏ハヌマーンでアナーキー・イン・ザ・1K
たった&0秒でも長く眠りたい

```
文法は整数の代わりに`&{要素のインデックス}`を書くだけです。  
要素参照を使った場合、上述の問題点が解決できています。

> ２回つけるのはいかんよ

要素参照の要素参照(2個以上の`&`)はサポートしていません。  
以下のコードはシンタックスエラーになります。

```
# シンタックスエラー
たった&&0秒でも長く眠りたい
```

## ASCII記法
正直、毎回歌詞を書くのは長くて開発体験が悪いので簡便なASCII記法を用意しています。  
例えば17の倍数を判定するプログラムはASCII記法では以下のようになります。  

```
# 現在のセルが17の倍数か判定
# ASCII版
%17
?
 echo "17の倍数"
 cr
:
 echo "17の倍数ではない"
 cr
;


# 現在のセルが17の倍数か判定
# 歌詞で書いた場合 (再掲)
何しろ僕らは17歳だった
どうして?の問いに
 捨て看板の女がぼやく「17の倍数」
 CR人間模様気付けばそれの虜になってる
愛してるって
 捨て看板の女がぼやく「17の倍数ではない」
 CR人間模様気付けばそれの虜になってる
答えになってないぜ兄さん

```

ASCII版においても１行につき１命令のルールは変わらないことに注意してください。

また、hanumanバイナリは`--to-lyrics`、`--to-ascii`オプションを用意していて、それぞれ歌詞への変換、ASCIIへの変換を機械的にしてくれます。

同じファイル内に歌詞とASCII記法が混じっていてもコードは動きますが、可読性のために統一することを推奨します。

## キーワード
以下が使用可能なキーワードの一覧です。  
Nは正の整数、もしくは要素参照です。  

| ASCII | 歌詞 | 機能 |
| --- | --- | --- |
| +N | たったN秒でも長く眠りたい | 要素にNを足す |
| -N | 見張り番の俺の落ち度を糾弾N円奪って先輩消える | 要素からNを引く |
| *N | ヘッドホンをしてN秒ごとに変わる表情 | 要素にNをかける |
| /N | 零コンマN秒で片付く命 | 要素をNで割る |
| %N | 何しろ僕らはN歳だった | 要素に{(現在の要素の値) mod N}の値を代入する |
| _ | およそ空っぽの頭の中やけに響く英語のアナウンス | 要素に0を代入する |
| rand | 名前を聞かれ思わず出鱈目な偽名を名乗ってしまった | 要素に乱数(-2^16~2^16)を入力 |
| @N | 演奏ハヌマーンでアナーキー・イン・ザ・NK | N番目の要素にインデックスを移動 |
| [ | 気に喰わんね輪廻の概念 | ループ開始 |
| ] | 全くを以って気に入らないね| ループ終了 |
| ? | どうして?の問いに | 条件分岐を開始 |
| : | 愛してるって | 条件分岐else部の開始 |
| ; | 答えになってないぜ兄さん | 条件分岐終了 |
| fn_{関数名} | そういちいち怒鳴るなって誰だって{関数名}したい | 関数定義開始 |
| end_fn | 言う？武闘派に遭遇して同じように言う？ | 関数定義終了 |
| call_{関数名} | もういちいち言わんだけで俺だって{関数名}したい | 関数呼び出し |
| pd | 換気口の下でギニアピッグが云う | 要素の値を数字として表示 |
| pu | こめかみを指して痩せた鴉が云う | 要素の値をunicode pointとして解釈し文字を表示 |
| echo “X” | 捨て看板の女がぼやく「X」 | Xを標準出力にプリント |
| cr | CR人間模様気付けばそれの虜になってる| 改行を標準出力にプリント |


## スタイルガイド

> 守られるか無視される以外には用途の無いスタイルガイド

以下はあくまでガイドです。破ってもコードは動きます。
- ファイル名の拡張子は.hnmnとする
- 関数、条件分岐、ループ内の歌詞はインデントする
- ASCII記法と歌詞を同じファイル内で混ぜない。`--to-lyrics`, `--to-ascii`オプションを活用する
- ハヌマーンを聴きながらコーディングすることを推奨します

## インストール方法
ビルド済みバイナリがリリースにあるのでお使いの環境向けのバイナリをダウンロードしてください。

またzig (v0.15)を使ってビルドすることも可能です。  
特に依存するソフトウェアもないので以下のコマンド一発でビルドできるはずです。
```
$ make

# インストールされたか確認
$ ./hanuman -v
```
